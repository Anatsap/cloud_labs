# Навантажувальний тест

Тест створено в k6. Кожен віртуальний користувач повторює цикл: 1 запис і 9 читань. Опис і результати: `docs/LOADTEST.md`.

## Що потрібно

1. Встановлений k6 (`k6 version`).
2. Розгорнутий сервіс (`terraform apply`) або локальний `docker compose up`.

## Запуск

З кореня проєкту:

```bash
./loadtest/run.sh
```

Адреса сервісу й пароль беруться з `terraform output`.

| Команда | Що робить |
|---|---|
| `./loadtest/run.sh` | повний тест (10 хвилин, N = 40) |
| `VUS=60 ./loadtest/run.sh` | повний тест з іншим N |
| `QUICK=1 VUS=2 ./loadtest/run.sh` | короткий пробний запуск (40 секунд) |

Результати зберігаються в папці `loadtest/results/`.
