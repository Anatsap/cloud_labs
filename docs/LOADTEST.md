# Звіт з навантажувального тестування (Load Testing)

## Опис сценарію (`loadtest/loadtest.js`)
Сценарій імітує реальну поведінку користувачів із профілем **«мало записів, багато читань»**:
1. Один віртуальний користувач (VU) у циклі виконує **1 операцію запису** (наприклад, створення нового автомобіля з унікальним `Idempotency-Key`).
2. Після цього виконує **8 операцій читання**: перегляд загального списку автомобілів, запит конкретного автомобіля за ідентифікатором (включно зі щойно створеним) та отримання супутніх даних.
## Фази навантаження
Тест виконує три чіткі фази (кількість користувачів $N$ підібрана так, щоб на сталому навантаженні спрацювало горизонтальне масштабування сервісу):
1. **Наростання (Ramp-up):** від 0 до $100$ користувачів за 2–3 хвилини.
2. **Стале навантаження (Steady state):** $100$ активних користувачів протягом 5 хвилин.
3. **Спад (Ramp-down):** плавне зниження до 0 користувачів за 2 хвилини.

## Команда запуску
Тестування запускається однією командою з кореня проєкту:
```bash
bash loadtest/run.sh
